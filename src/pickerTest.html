📋 Smart Sheet Selection

🎯 Auto-Selection: Sheets you've previously authorized will be automatically selected when you click "Select Files"!

➕ Add More: Use "Add Another File" to authorize and select additional sheets from the picker.

Desktop Multi-Select:

  • Windows: Hold Ctrl and click multiple files
  • Mac: Hold Cmd and click multiple files
  • Selection: Selected files will have a blue highlight

Mobile/Touch Multi-Select Options:

  • Method 1: Try long-pressing on files to select multiple
  • Method 2: If that doesn't work, select one file at a time using the "Add Another File" button
  • Selection: Selected files will have a blue highlight or checkmark
  • Fallback: The app will help you collect multiple files even if native multi-select doesn't work

Finish: Click "Select" when you've chosen all desired files, then click "Continue" to proceed
