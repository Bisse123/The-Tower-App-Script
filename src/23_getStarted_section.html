🚀 Get Started: Set Up Your IDS Sheets™

What are IDS Sheets™?
IDS Sheets™ are special Google Sheets™ used to manage your data for "The Tower" to make informed decisions in the game.
  • Effective Paths Sheet™: The main sheet™ that uses your data to calculate your best upgrade path.
  • IDS Master Sheet™: The main sheet™ that links all your data together.
  • IDS Subsheets™: One for each type shown in IDS Master (Laboratory, Workshop, etc.).
  • IDS Collection Sheet™: An all-in-one sheet™ that combines the Master and subsheets.
How to set up:
  • First you must choose if you want to use the IDS Master or IDS Collection to store your data
    Note: Both options are valid, it doesn't make much difference. With ID Master you open multiple tabs in your browser. With IDS Collection you have multiple tabs within the sheet.
    • IDS Master + Subsheets: Keeps information and tools organized in different files by category (Lab, Workshop, etc.).
    • IDS Collection: Centralized all-in-one sheet™ for those who prefer to have everything in one file.
  • Quick Setup (Recommended): Automatically create and connect all sheets™ in your Drive
    1. Templates will be copied to your "The Tower" folder in Google Drive
    2. Input your game data for each subsheet
    3. Now you are ready to use the Effective Paths Sheet™ to optimize your game progress
  • Manual Setup: Copy sheets™ manually and connect them yourself
    1. Use the template links below to copy each sheet™ manually
    2. Connect IDS Master in each subsheet
    3. Connect subsheets in IDS Master
    4. Connect IDS Master or Collection in the Effective Paths Sheet™
    5. Manually input your game data and you're ready to go
  • Future Updates:
    Note: Links are located in the "IDS" tab (Home Page for IDS Collection)
    1. Open your IDS Master, IDS Collection or Effective Paths Sheet™
    2. Use the addon or web app to update your Sheets™
    3. It will automatically create the new Sheets™ for you
    4. Transfer your data using the "Import Data" button
    5. Open the newly created Sheets™ using the links provided
    6. Check that your data looks correct
    7. Move and rename your Sheets™ using the "Move Sheets" button
