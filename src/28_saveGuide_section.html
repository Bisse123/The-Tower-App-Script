The Tower keeps all your progress in a single file called playerInfo.dat. Get that file onto this computer or into Google Drive, then load it in the section below. Pick the route that matches where you play.

📱 Android / Emulators
Android 12 or older

On these versions a file manager can still be granted access to /Android/data, so everything can be done on the device itself. Your version is under Settings → About phone → Android version.

Fastest to set up and works with any cloud app. Downside: nothing gets overwritten, so copies pile up (playerInfo.dat, playerInfo (1).dat, …) and you have to grab the newest one yourself. Not automatic: you bring the file into this app however you like.

  1. Install Total Commander from the Play Store.
  2. Tap "Internal Share" and grant it Manage permissions (a dialog pops up).
  3. Navigate to /Android/data.
  4. Tap "Installed Apps", it asks for permission again. Click "Use this folder" (it won't work if you open The Tower's folder before clicking "Use this folder").
  5. Navigate to /com.TechTreeGames.TheTower/files, that's where playerInfo.dat lives.
  6. Also install your cloud app (Google Drive, Dropbox, OneDrive…) from the Play Store.
  7. Long-press playerInfo.dat → "Send to" → your cloud app. Grant permission if it asks.
  8. On your PC, download the newest playerInfo file from that cloud and load it below with "From your computer".

A free app that mirrors The Tower's save folder straight to Google Drive on a schedule, overwriting the same files each time, so "Choose file from Drive" below always gives you your latest save with no manual step.

  1. Install FolderSync from the Play Store (the free version is enough) and open it.
  2. Accept the terms. When prompted, grant "All files access" and "/Android/data" access, and disable battery optimization so it keeps syncing in the background. "/Android/OBB" access is NOT needed. Tap Finish.
  3. When it offers to connect a cloud, tap "Add account", choose Google Drive, sign in, and grant permissions. (Use Google Drive so this app can read it.)
  4. Open the folder-pairs tab (the folder icon, 2nd from the left in the bottom bar), then tap "Create folder pair" and choose "To right" (one-way: phone → cloud).
  5. Left side (device storage): navigate to /Android/data/com.TechTreeGames.TheTower/files/ and tap "Select folder".
  6. Right side (Google Drive): pick the folder you want to sync your save to.
  7. Open the "Scheduling" tab and turn on a sync interval (e.g. every hour) so it runs on its own.
  8. Scroll the pair's tabs right to "Filters" (General · Scheduling · Sync options · Connections · Filters · Webhooks) and add two rules so only your save syncs, not Unity's bulky cache: Exclude · Folder name contains · "Unity", and Exclude · Folder name contains · "il2cpp".
  9. Review the summary, save the pair, and run it once to seed the Drive folder.
  10. From now on, use "Choose file from Drive" below and pick playerInfo.dat from that folder - it's always your newest save.

More one-time setup (a personal Google OAuth client), but afterwards each send overwrites the same file in Google Drive, so "Choose file from Drive" below always gives you your latest save. You still tap to send each time (it isn't scheduled like FolderSync). Independent of the other options.

  1. Install Total Commander from the Play Store.
  2. Tap "Internal Share" and grant it Manage permissions (a dialog pops up).
  3. Navigate to /Android/data.
  4. Tap "Installed Apps", it asks for permission again. Click "Use this folder" (it won't work if you open The Tower's folder before clicking "Use this folder").
  5. Navigate to /com.TechTreeGames.TheTower/files, that's where playerInfo.dat lives.
  6. Set up Total Commander's Drive plugin (one-time): download the Drive plugin, then in Total Commander's home page tap "Drive" → "Add Google Account".
  7. Create a personal OAuth client so the plugin can reach your Drive. Full reference: ghisler.com/googledriveandroid.htm.

    Do this part on a PC, in the Google Cloud Console (console.cloud.google.com), signed in with the same Google account:

    1. Create a new project (any name will do).
    2. In "APIs & Services" → "Library", find the Google Drive API and enable it.
    3. Configure the OAuth consent screen as "External" and add your own Google account as a test user.
    4. In "Credentials", create an OAuth client ID and note the client ID/secret it gives you.
    5. Enter those in Total Commander's Drive plugin when it asks.

    Google reshuffles this console fairly often - the ghisler.com page linked above keeps click-by-click screenshots, so follow it if anything looks different.

  8. Back in Total Commander, tap "Drive" → your Google account and grant permissions; you should see the "app" you just created.
  9. Long-press playerInfo.dat → "Send to" → choose Total Commander (not the Google Drive app directly) and navigate to your Drive folder. Doing it this way OVERWRITES the file each time instead of piling up copies.
  10. From now on, use "Choose file from Drive" below and pick that file.
Android 13 or newer

Android 13 locked down /Android/data: file managers, the system picker and cloud apps can no longer open it, so options 1–3 do not work here. Pull the file from a PC with adb instead - that also covers emulators, which run Android too.

adb is Android's debug tool and it can read /Android/data even when apps can't. Emulators already ship a copy of it; for a real phone, download "SDK Platform Tools" from Google and turn on USB debugging (Settings → About phone → tap "Build number" 7 times → Developer options → USB debugging).

  1. Close The Tower first so your latest progress is written to the file, then leave the emulator running / plug the phone in.
  2. Find your adb:
    • LDPlayer: its install folder, e.g. C:\Program Files\LDPlayer\LDPlayer9 - the file is called "adb" or "adb.exe".
    • BlueStacks: its install folder, e.g. C:\Program Files\BlueStacks_nxt\ - the file is called "HD-adb.exe".
    • Real phone: adb.exe from the SDK Platform Tools folder you downloaded.
  3. Open PowerShell in that folder: Shift + right click in the folder → "Open PowerShell window here".
  4. Check the device is seen (on a phone, accept the "Allow USB debugging" prompt):
    ./adb.exe devices
  5. Pull the save into that same folder:
    ./adb.exe pull /sdcard/Android/data/com.TechTreeGames.TheTower/files/playerInfo.dat .
  6. playerInfo.dat is now in that folder - load it below with "From your computer".

If you do this often, save the lines below as e.g. getSave.bat and just double-click it. This example is for BlueStacks and drops the save on your Desktop - change the ADB path to your own emulator (or SDK Platform Tools) and SAVE to wherever you want the file. 

@echo off
set ADB="C:\Program Files\BlueStacks_nxt\HD-adb.exe"
set SAVE="%USERPROFILE%\Desktop\playerInfo.dat"

echo Connecting to BlueStacks...
%ADB% devices

echo.
echo Saving The Tower...
%ADB% pull /sdcard/Android/data/com.TechTreeGames.TheTower/files/playerInfo.dat %SAVE%

echo.
echo Done!
pause
🍎 Mac

Open Terminal and run:

open -R "$(find ~/Library/Containers -name playerInfo.dat -print -quit)"

Finder opens with playerInfo.dat selected - load it below with "From your computer".
