📋 File Access Management

🎯 Automatic Check: The app will automatically check which files need access permissions when you load the page.

🔓 Grant Access: If files need permission, use the "Grant Access to Files" button to authorize them through Google™ Picker.

🖥️ Desktop Tips:

  • Click & Drag: Click and drag to select multiple files
  • Windows: Hold Ctrl and click multiple files
  • Mac: Hold Cmd and click multiple files
  • Selection: Selected files will have a blue highlight

📱 Mobile Tips:

  • Double tap a file to select it
  • Look for blue highlights on selected files
